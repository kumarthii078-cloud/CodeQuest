# CodeQuest
CodeQuest is an web-based coding Challenge platform where users pick a difficulty ,write  a java code,and see the output instantly

**Learn. Code. Compete. Improve.**

CodeQuest is a browser-based coding practice platform. Choose a difficulty
level, get a programming challenge, write your Java solution, and run it to
see the output right on the page.

## Features
- Three difficulty levels: Easy, Medium and Hard
- A different coding question for each level
- Built-in code editor for writing Java programs
- Submit button that compiles and runs the code and shows the real output
- Clear button to reset the editor and output
- Clean, dark-themed responsive interface

## Tech Stack
- HTML, CSS, JavaScript
- Judge0 API for compiling and running Java code

## How to Run
1. Clone the repository:
   `git clone https://github.com/kumarthii078-cloud/codequest.git`
2. Open `index.html` in your browser (or use VS Code Live Server).
3. Choose a difficulty, write your code, and click **Submit**.

## Project Structure
- `index.html`: page layout and main logic
- `style.css`: styling
- `script.js`: app scripts
- `questions.js`: challenge questions
